# My Diary & TODO アプリ

HTML/CSS/JavaScriptのみで構築された、シンプルで使いやすい日記とTODO管理アプリです。
ブラウザの `localStorage` を使用してデータを保存するため、サーバー不要で動作します。

## 1. はじめに
このアプリは、日々の出来事を記録する「日記」機能と、やるべきことを管理する「TODO」機能を備えたシンプルなツールです。ブラウザにデータが保存されるため、会員登録なしですぐに使い始めることができます。

---

## 2. 基本的な使いかた

### タブの切り替え
画面上部の **[日記]** ボタンと **[TODO]** ボタンを押すことで、それぞれの機能を切り替えることができます。

### 日記機能
1.  **入力**: 「今日のできごとを書きましょう...」と書かれたエリアに文章を入力します。
2.  **保存**: [保存する] ボタンを押すと、入力した内容が現在の日時とともにリストに追加されます。
3.  **削除**: 各日記の右上にある [削除] ボタンを押すと、その項目を消去できます。

### TODO機能
1.  **追加**: 「新しいタスクを入力...」の欄にタスクを書き込み、[追加] ボタンを押します。
2.  **完了チェック**: タスクの左側にあるチェックボックスを押すと、完了状態（打ち消し線）になります。
3.  **進捗確認**: リストの上部に「X / Y 完了」という形式で、現在の進捗状況が表示されます。
4.  **削除**: タスクの右側にある [削除] ボタンで、項目を完全に消去できます。

---

## 3. データの保存について
- このアプリはブラウザの `localStorage` という機能を使用してデータを保存しています。
- **サーバーには送信されません。** データはお使いのデバイス（PCやスマートフォン）のブラウザ内にのみ保存されます。
- ブラウザのキャッシュや履歴を完全に削除すると、データも消去される場合がありますのでご注意ください。

---

## 4. 推奨環境
- Google Chrome, Safari, Microsoft Edge などの最新のブラウザ。
- スマートフォン、タブレット、PCのいずれでも利用可能です。
