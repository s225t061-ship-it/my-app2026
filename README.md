# My Diary & TODO App

HTML/CSS/JavaScriptのみで構築された、シンプルで使いやすい日記とTODO管理アプリです。
ブラウザの `localStorage` を使用してデータを保存するため、サーバー不要で動作します。

## 機能
- **日記**: その日の出来事を記録。自動的に日時が保存されます。
- **TODO**: タスクの追加、完了チェック、削除が可能。
- **レスポンシブデザイン**: スマートフォンとPCの両方で快適に使用できます。
- **データ保存**: ブラウザを閉じてもデータが保持されます。

## GitHub Pages での公開方法
1. このリポジトリをGitHubにプッシュします。
2. GitHubリポジトリの **Settings** タブをクリックします。
3. 左サイドバーの **Pages** を選択します。
4. **Build and deployment** セクションの **Branch** で `main` ブランチを選択し、 `Save` をクリックします。
5. 数分後、上部に表示されるURL（例: `https://username.github.io/repo-name/`）にアクセスしてアプリを確認できます。
