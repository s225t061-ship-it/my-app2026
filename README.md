# 📓 My Daily Life & TODO

> **日々のカケラを、ここに綴ろう。**

「My Daily Life」は、あなたの毎日をちょっとだけ便利に、そして楽しく記録するためのデジタル・ノートブックです。
HTML/CSS/JavaScriptのみで構築された、軽快に動くシンプルなアプリです。

---

## 📖 このノートでできること

このアプリには、あなたの毎日を支える2つの大事なページがあります。

### 🖋️ 日記のページ (Diary)
その日の出来事や、ふと感じたことを自由に書き留める場所です。
*   **記録する**: テキストを入力して「保存」するだけ。
*   **振り返る**: 保存した日時は自動で記録されるので、いつの思い出かすぐわかります。
*   **整理する**: 不要になったメモはいつでも「削除」してスッキリ。

### ✅ TODOのページ (TODO)
今日やるべきこと、忘れちゃいけないことを管理する場所です。
*   **書き出す**: 新しいタスクをサッと追加して、頭の中を整理。
*   **完了させる**: 終わったタスクにチェックを入れる瞬間の達成感を！
*   **進捗をみる**: 「何個中、何個終わったか」がひと目でわかります。

---

## 💡 お使いいただく際のヒント

*   **サクサク切り替え**: 画面トップのボタンで、日記とTODOをパッと行き来できます。
*   **自分だけの保存場所**: データはあなたのブラウザ（`localStorage`）に保存されます。サーバーには送信されないので、自分だけの秘密のノートとして使えます。
*   **どこでもいっしょ**: スマートフォンでもPCでも、お好きなデバイスで開けます。

> [!IMPORTANT]
> **データの保存について**
> ブラウザのキャッシュや履歴を完全に削除すると、ノートの内容も消えてしまうことがあります。大切な記録は、ブラウザの管理にご注意ください。
